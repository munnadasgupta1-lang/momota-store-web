momota-store# Momota Store Web

A simple full-store starter for a modern storefront built with Express and static frontend assets.

## Features

- Public storefront landing page
- Product catalog rendered from an API
- Cart count interaction in the UI
- Responsive layout for desktop and mobile
- Ready for additional pages or integration with a real backend

## Tech stack

- Node.js
- Express
- Vanilla JavaScript
- HTML/CSS

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the app:
   ```bash
   npm start
   ```
3. Open the app in your browser:
   ```bash
   http://localhost:3000
   ```
